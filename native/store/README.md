# Maxora sugli Store — cosa è pronto e cosa resta

Pronto (non serve pagare niente):
- App nativa iPhone/Android in `native/` (Capacitor): GPS anche a schermo spento, notifiche, icone, apertura.
- Build automatica su GitHub: Actions › "App nativa" › Run workflow → APK Android di prova da installare + controllo che l'app iPhone si compili.
- Pagine pubbliche: privacy.html e support.html (4 lingue).
- "Cancella i miei dati" nell'app (obbligatorio per Apple).
- Testi delle schede (scheda.md), note per la revisione e risposte privacy (revisione-apple.md), screenshot (cartella screenshots/).

Quando decidi di pubblicare:
1. Apple: iscriviti all'Apple Developer Program (99 €/anno) con il tuo Apple ID.
2. Google: account sviluppatore Google Play (25 $ una tantum).
3. Mi dai accesso (chiavi per la firma): aggiungo firma e invio automatico al workflow.
4. Incolli i testi di scheda.md, carichi gli screenshot, compili privacy ed età con revisione-apple.md.
