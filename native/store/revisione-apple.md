# Note per la revisione Apple (App Review Information › Notes)

Maxora is a free community map for the island of Fuerteventura (Canary Islands, Spain). No login is required: an anonymous session is created automatically.

How to test:
1. Allow location ("While Using", then "Always" when asked) — any location works; outside the island the map simply shows Fuerteventura.
2. Tap "Report something" to post a road alert (crash, traffic, roadworks…). It appears for everyone and expires on its own.
3. Open the modes menu (top right) to try Surf, Bike, Run and Campervan.

Background location (UIBackgroundModes: location) is used only to warn drivers about road hazards and fixed speed cameras ahead while the screen is off or another navigation app is open. The route is never stored or uploaded.

Police: users can mark generic "police presence". The app never shows an exact position, only an approximate area of about 2.5 km, which expires after 20 minutes. It does not show DUI/alcohol checkpoints. Fixed speed cameras come from public data (OpenStreetMap/DGT). Alerting about traffic police is legal in Spain.

Account deletion: Settings › Delete my data (deletes the account and personal data).
Support: https://stocked-app.github.io/MAXORA/support.html · Privacy: https://stocked-app.github.io/MAXORA/privacy.html
